**Тема:** Выбор, сбор и предварительный анализ тематического корпуса текстов  
**Дисциплина:** Информационный поиск  

---

## 1. Выбор темы и источников

В качестве тематики для сбора корпуса текстов я выбрал **«Космонавтику и авиацию» (Space & Aviation)**. Тема обширная, на английском языке доступно огромное количество качественных материалов.

Для формирования коллекции я взял два разнотипных источника:
1. **Wikipedia (английский раздел)** — энциклопедические статьи по ракетостроению, космическим аппаратам, космонавтам, спутникам, миссиям NASA/Роскосмоса и истории авиации.
2. **Spaceflight Now / SpaceNews** — отраслевые новости о запусках ракет, испытаниях, спутниковых группировках и контрактах.

Целевой объем корпуса: суммарно **не менее 30 000 документов** из двух источников (без обязательной жесткой пропорции, например ~26 000 из Википедии и ~4 000 из новостей).

## 2. Структура работы и файлов

Все исходные коды, скачанные данные и отчеты хранятся локально в папке `lab 1`:

```text
lab 1/
├── main.py                 # Главный скрипт: запускает по очереди сбор, очистку и статистику
├── download_wikipedia.py   # Сбор статей Википедии через API
├── download_spacenews.py   # Сбор новостей космонавтики
├── extract_text.py         # Очистка HTML и извлечение чистого текста в TXT
├── corpus_stats.py         # Подсчет итоговой статистики корпуса
├── README.md               # Этот отчет
├── data_raw/               # Папка с «сырыми» данными (HTML в JSON)
│   ├── wikipedia_en/
│   └── spacenews/
├── data_text/              # Папка с очищенными текстами (.txt)
│   ├── wikipedia_en/
│   └── spacenews/
└── out/                    # Папка с отчетами
    ├── stats.txt           # Текстовый отчет со статистикой
    └── stats.json          # Статистика в формате JSON
```

---

## 3. Сбор и подготовка данных

1. **Сбор сырых данных (`data_raw/`):**
   - Для Википедии обходятся категории `Space exploration`, `Astronautics`, `Human spaceflight`, `Spacecraft`, `Aviation`, `Aircraft`, `Rocketry` и их подкатегории до 6 уровня глубины.
   - Для новостей обходятся страницы архива Spaceflight Now.
   - Каждый скачанный документ сохраняется в формате JSON со всеми метаданными: URL, заголовок, дата, автор, исходный HTML-код и timestamp загрузки.

2. **Очистка текста (`data_text/`):**
   - Скрипт `extract_text.py` парсит сохраненный HTML через `BeautifulSoup`.
   - Удаляются скрипты, стили, шапки сайта, меню, навигационные шаблоны, плашки копирайта и реклама.
   - Чистый связный текст статьи сохраняется в файл `.txt` в кодировке UTF-8. Слишком короткие страницы (меньше 500 символов) отсеиваются.

---

## 4. Результаты анализа корпуса

Скрипт `corpus_stats.py` считает строго 4 требуемых по заданию показателя:
1. **Количество документов:** общее число сырых файлов и документов с успешно выделенным текстом (суммарно и по каждому источнику).
2. **Размер примеров «сырых» документов:** общий объем исходных JSON-файлов в мегабайтах и байтах, а также диапазон размеров файлов (от минимального до максимального в КБ).
3. **Размер текста, выделенного из «сырых» данных:** суммарный объем чистого текста в мегабайтах, байтах и символах.
4. **Средний размер документа и средний объём текста в документе:** средний размер сырого файла (в КБ) и средний объем текста одной статьи (в КБ и количестве символов).

## 5. Как запускать лабу

Все команды запускаются из папки `lab 1`:

```bash
cd "lab 1"
```

### Запуск всего конвейера целиком (по умолчанию на 30 000 док.):
```bash
python3 main.py --step all
```

### Либо запуск отдельных этапов:
```bash
# 1. Скачать новости космонавтики:
python3 download_spacenews.py

# 2. Скачать статьи из Википедии:
python3 download_wikipedia.py

# 3. Извлечь и очистить текст:
python3 extract_text.py

# 4. Посчитать статистику:
python3 corpus_stats.py
```

Результаты анализа сохраняются в `out/stats.txt` и `out/stats.json`.
